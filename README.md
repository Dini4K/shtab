Единое Техническое Задание (ТЗ) на модуль "ШТАБ" для OpenCart
 Цель: Создание модульной AI-платформы для автоматизации e-commerce с поэтапной разработкой, начиная с модуля репрайсинга.

1. ОБЩИЕ ТРЕБОВАНИЯ
	•	Платформа: OpenCart 3.x+
	•	Установка: Ручная через FTP + SQL-скрипт (без OCMOD)
	•	Язык: Русский
	•	Совместимость: PHP 8.1+, MySQL 8.0+, InnoDB, utf8mb4, Redis (обязательно для очередей)
	•	Безопасность:
	◦	hasPermission во всех контроллерах админки
	◦	CSRF-токены во всех формах и AJAX-запросах
	◦	Шифрование API-ключей маркетплейсов и сервисов с использованием AES-256-GCM
	◦	Валидация и санитизация всех входящих данных
	◦	RBAC (Role-Based Access Control): роли admin (полный доступ), manager (ограниченное управление), viewer (только просмотр)
	•	Архитектура:
	◦	Модульность: Каждый функциональный блок разрабатывается и подключается отдельно
	◦	Сервисный слой: Для взаимодействия между модулями используются общие Service-классы, что исключает прямые зависимости
	◦	Асинхронность: Тяжелые операции (массовый репрайсинг, импорт заказов) выполняются через очереди на Redis
	◦	AI-ядро: Python-микросервисы (Flask/FastAPI) для прогноза спроса, ML-логистики и др., взаимодействие через API/очереди
	•	Уведомления: Telegram-бот и email для критических событий (просрочки заказов, ошибки API, срабатывание правил)
	•	Уникализация: Все имена файлов и таблиц БД имеют префикс shtab_

3. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ (ПОРЯДОК РАЗРАБОТКИ)
3.1. ЭТАП 0: ФУНДАМЕНТ (Неделя 1)
	•	Цель: Создать каркас модуля, главное меню и систему установки
	•	Модули: SHTAB Core (shtab.php, shtab_menu.php)
	•	БД: Скрипт install.sql создает таблицу настроек oc_shtab_setting
3.2. ЭТАП 1: ЯДРО ДАННЫХ (Недели 2-3)
	•	Цель: Реализовать базовые сущности, необходимые для работы репрайсинга
	•	Модули:
	1	SHTAB Settings: Общие настройки модуля (API-ключи, настройки Redis)
	2	SHTAB Products: Управление товарами, себестоимостью, привязкой к маркетплейсам. Реализует ProductService
	•	БД: oc_shtab_product, oc_shtab_product_to_marketplace
3.3. ЭТАП 2: РЕПРАЙСИНГ (Недели 4-6) - ПЕРВАЯ ОЧЕРЕДЬ
	•	Цель: Реализовать полный функционал контроля и автоматического изменения цен
	•	Модуль: SHTAB Repricing
	•	Функционал:
	◦	Защита цен от падения ниже RRP
	◦	Визуальный No-Code конструктор правил (drag-and-drop на Vue.js/Rete.js)
	◦	Менеджер CRON-заданий для автоматического выполнения
	◦	Мониторинг и парсинг цен конкурентов (с анти-скрапинг мерами)
	◦	Импорт/экспорт цен, история изменений, аудит
	◦	Уведомления о критических изменениях
	◦	Дашборд аналитики: динамика цен, маржи, KPI
	•	БД: oc_shtab_repricing_rule, oc_shtab_repricing_task, oc_shtab_price_history
3.4. ЭТАП 3: ЗАКАЗЫ И ЛОГИСТИКА (Недели 7-8)
	•	Модули: SHTAB Orders, SHTAB Logistics
	•	Функционал: Импорт заказов, контроль сроков, верификация адресов, интеллектуальный подбор ТК
3.5. ЭТАП 4: АНАЛИТИКА И РАСШИРЕНИЕ (Недели 9-10)
	•	Модули: SHTAB Analytics, SHTAB Suppliers
	•	Функционал: Расчет прибыли, ROI, RFM-анализ, управление поставщиками
3.6. ЭТАП 5: AI И АВТОМАТИЗАЦИЯ (Недели 11-12)
